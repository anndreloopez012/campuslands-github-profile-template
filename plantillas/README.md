# Tipos de plantilla

Todas las plantillas usan las mismas variables principales.

El estudiante debe elegir una sola, copiar su contenido y pegarlo en el `README.md` del repositorio que tiene el mismo nombre que su usuario de GitHub.

## Opciones disponibles

| Plantilla | Archivo | Cuando usarla |
|---|---|---|
| Corporativa clasica | [corporativa-clasica.md](corporativa-clasica.md) | Para procesos formales, CV, entrevistas y perfil junior serio |
| Estilo graficos | [estilo-graficos.md](estilo-graficos.md) | Para un perfil visual completo: hero, badges, areas de experiencia, stack visual y graficos |
| Visual con graficos | [visual-graficos.md](visual-graficos.md) | Para estudiantes que quieren un perfil mas llamativo con estadisticas, actividad y badges |
| Compacta para reclutador | [compacta-reclutador.md](compacta-reclutador.md) | Para perfiles directos, rapidos de leer y enfocados en empleabilidad |

## Recomendacion

- Si estas empezando: usa `corporativa-clasica.md`.
- Si ya tienes varios proyectos: usa `visual-graficos.md`.
- Si quieres algo parecido al perfil visual de referencia: usa `estilo-graficos.md`.
- Si quieres algo simple para aplicar a empleo rapido: usa `compacta-reclutador.md`.

## Regla

Puedes usar graficos, badges y animaciones, pero la informacion debe ser real.

No pongas tecnologias que no puedas defender en entrevista.
