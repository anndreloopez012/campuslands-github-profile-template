# Buenas practicas corporativas para Guatemala

Un perfil profesional debe ayudar a que una empresa entienda rapidamente si vale la pena contactarte.

## Tono recomendado

Usa un tono:

- claro
- directo
- profesional
- honesto
- enfocado en valor

Evita:

- bromas internas
- exceso de emojis
- frases demasiado informales
- decir "soy experto" si estas empezando
- escribir textos largos sin estructura

## Como presentarte si eres junior

Correcto:

```text
Desarrollador Backend Junior en formacion, con enfoque en APIs REST, bases de datos relacionales y buenas practicas de Git.
```

Incorrecto:

```text
Soy programador experto en todo y hago cualquier sistema.
```

## Como hablar de experiencia si aun no tienes empleo formal

Puedes hablar de:

- proyectos academicos
- proyectos personales
- practicas
- colaboraciones
- ejercicios avanzados
- retos tecnicos

Ejemplo:

```text
He construido proyectos academicos enfocados en gestion de inventarios, APIs REST y dashboards administrativos.
```

## Informacion de contacto

Usa un correo profesional.

Correcto:

```text
nombre.apellido@email.com
```

Evita correos informales o dificiles de leer.

## Proyectos que ayudan a buscar trabajo

Prioriza proyectos que parezcan utiles para empresas:

- inventario
- gestion de clientes
- sistema de tickets
- dashboard de ventas
- API de usuarios y roles
- gestor de tareas
- control de pagos
- reportes administrativos
- integraciones con servicios externos

## Que no deberia aparecer

- informacion personal sensible
- numero de DPI
- direccion exacta
- telefono si no quieres recibir llamadas
- contrasenas o tokens
- frases ofensivas
- tecnologias falsas
- enlaces rotos
