# Stack Campuslands para perfiles GitHub

Este stack resume las tecnologias que se ensenan y que los alumnos pueden mostrar en su perfil si realmente las han trabajado.

## Stack completo

```text
Python, GitHub, HTML, CSS, JavaScript, MySQL I, MySQL II, MongoDB I, MongoDB II, Java, Node.js, PHP, C#, Spring Boot, Express, Laravel, .NET
```

## Variables recomendadas

```text
STACK_FRONTEND=HTML, CSS, JavaScript
STACK_BACKEND=Python, Java, Node.js, Express, PHP, Laravel, C#, .NET, Spring Boot
STACK_BASES_DATOS=MySQL I, MySQL II, MongoDB I, MongoDB II
STACK_HERRAMIENTAS=GitHub, Git, Docker, VS Code, Postman
SKILLICONS_LIST=python,github,html,css,js,mysql,mongodb,java,nodejs,php,cs,dotnet,spring,express,laravel,git,docker,vscode
```

El alumno puede mostrar el stack completo como ruta de aprendizaje de Campuslands, pero en su stack personal debe dejar solo lo que puede explicar en entrevista.
