# Como elegir tecnologias para tu perfil

No debes listar todas las tecnologias que existen. Debes listar las que realmente puedes defender.

## Nivel recomendado

Usa esta regla:

| Nivel | Cuando poner una tecnologia |
|---|---|
| Basico | Puedes crear ejercicios simples y explicar conceptos principales |
| Intermedio | Puedes construir proyectos pequenos sin copiar todo |
| Profesional inicial | Puedes integrarla en un proyecto real y explicar decisiones |

Si solo viste un video o instalaste la herramienta una vez, no la pongas como tecnologia principal.

## Como organizar el stack

### Frontend

Incluye tecnologias para interfaces:

- HTML
- CSS
- JavaScript
- TypeScript
- React
- Tailwind CSS

### Backend

Incluye tecnologias para servidores y APIs:

- Node.js
- Express
- PHP
- Laravel
- Java
- Spring Boot
- C#
- .NET

### Bases de datos

Incluye bases de datos que hayas usado en ejercicios o proyectos:

- MySQL
- PostgreSQL
- MongoDB
- SQL Server

### Herramientas

Incluye herramientas de trabajo:

- Git
- GitHub
- Docker
- VS Code
- Postman

## Ejemplo de mala seleccion

```text
HTML, CSS, JavaScript, TypeScript, React, Angular, Vue, Node, Express, Nest, PHP, Laravel, Java, Spring, Python, Django, Flask, MySQL, PostgreSQL, MongoDB, Oracle, AWS, Azure, Docker, Kubernetes
```

Problema: parece inflado si el estudiante no tiene proyectos reales con todo eso.

## Ejemplo de buena seleccion

```text
Frontend: HTML, CSS, JavaScript, React
Backend: Node.js, Express
Base de datos: MySQL, MongoDB
Herramientas: Git, GitHub, Docker
```

Es mejor verse claro y honesto que saturado.
