# Checklist final

Antes de publicar tu perfil, confirma cada punto.

## Informacion personal

- [ ] El nombre esta bien escrito.
- [ ] El rol objetivo es claro.
- [ ] La ubicacion esta correcta.
- [ ] El correo se ve profesional.
- [ ] El enlace de LinkedIn funciona.
- [ ] El enlace de GitHub funciona.
- [ ] El enlace del portafolio funciona o fue eliminado si no existe.

## Contenido profesional

- [ ] El perfil explica que sabes hacer.
- [ ] La propuesta de valor no suena generica.
- [ ] No hay frases informales.
- [ ] No hay errores de ortografia visibles.
- [ ] No hay informacion falsa o exagerada.

## Tecnologias

- [ ] Eliminaste tecnologias que no manejas.
- [ ] Organizaste tecnologias por area.
- [ ] Puedes explicar cada tecnologia que aparece.
- [ ] No usaste demasiados badges sin sentido.

## Proyectos

- [ ] Tienes al menos 2 proyectos destacados.
- [ ] Cada proyecto tiene descripcion clara.
- [ ] Cada proyecto tiene tecnologias usadas.
- [ ] Cada enlace abre correctamente.
- [ ] Los repositorios destacados tienen README propio.

## GitHub

- [ ] El repositorio tiene el mismo nombre exacto que tu usuario.
- [ ] El repositorio es publico.
- [ ] El archivo se llama `README.md`.
- [ ] El `README.md` esta en la raiz del repositorio.
- [ ] No quedaron variables como `{{NOMBRE_COMPLETO}}`.

## Revision final

- [ ] Abriste tu perfil publico y se ve correctamente.
- [ ] Revisaste el perfil desde celular.
- [ ] Pediste feedback a un companero o instructor.
- [ ] Guardaste una fecha de ultima actualizacion.
